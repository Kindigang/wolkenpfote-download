## So installierst du sie

2. Die Datei antippen. Beim ersten Mal fragt Android, ob der Browser Apps installieren darf: erlauben.
3. „Installieren“ bzw. bei einem Update „Aktualisieren“ antippen.

Bei einem Update bleibt der Spielstand erhalten.
